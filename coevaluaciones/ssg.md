# Generadores de Sitios Estáticos (SSG)

Un **SSG** (*Static Site Generator*) es una herramienta que toma archivos de texto plano (generalmente escritos en Markdown) y plantillas, y los procesa para construir un sitio web HTML completamente estático antes de subirlo al servidor.

## Comparativa: Jekyll, Hugo y Astro

Tras investigar estas tres herramientas principales, podemos observar las siguientes diferencias clave:

| Generador (SSG) | Lenguaje Base | Ventaja Principal | Caso de Uso Ideal |
| :--- | :--- | :--- | :--- |
| **Jekyll** | Ruby |Es increíblemente fácil de aprender, tiene un ecosistema gigante de temas antiguos pero estables, y su integración con GitHub Pages sigue siendo la más fluida para publicar un blog en minutos sin configurar servidores. | Blogs clásicos y sitios de documentación. |
| **Hugo** | Go | Su velocidad es inigualable (puede compilar miles de páginas en menos de un segundo). Su gestión de contenido es extremadamente potente, lo que lo hace ideal para documentación, portales de noticias o catálogos masivos. | Sitios web masivos con mucho contenido. |
| **Astro** | JS / TypeScript | Permite construir la web usando tus frameworks favoritos (puedes mezclar componentes de React, Vue y Svelte en la misma página). Produce sitios web increíblemente rápidos para el usuario final y sus colecciones de contenido (Content Collections) ofrecen validación de datos estricta con TypeScript. | Proyectos modernos orientados al rendimiento extremo. |
